Python 3.11.9 / PyTorch 2.11.0+cu128 / FastAPI 0.141.1 / Open3D 0.20.0 が導入済みのWindows環境を使用しました。Python側は意味検索のモデル取得を無効化し、モデル取得をオフラインにして実行しています。

```text
python -m pytest -q --disable-warnings --maxfail=5
357 passed, 2 warnings, 9 subtests passed

node --test --experimental-test-isolation=none tests/*.test.mjs
86 passed, 0 failed
```

この実行環境ではNodeの子プロセス起動に制限があるため、ファイルごとのプロセス分離を無効にしています。一般のローカル環境では `node --test tests/*.test.mjs` を利用できます。Python実行時には依存ライブラリの非推奨警告がありましたが、テストの失敗はありませんでした。

合成デモの旧IDは生成状況の取得でUUID形式エラーになるため、公開版では固定のデモ用UUIDに変更し、生成・表示・検索を再確認しました。

## 今回実行していないこと

- クリーンな仮想環境への依存インストール全体、Linuxでの起動、Dockerのビルド。
- モデルの新規ダウンロードや、実写動画からのGPUフル生成。
- 複数部屋・複数利用者による精度や探索時間の定量評価。
- 実機カメラ・マイクを使う全操作の再試験。

単体テストの成功を、実空間の再構成精度や検索正答率の保証として扱っていません。
