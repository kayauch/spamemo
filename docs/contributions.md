# 制作で担当したこと

スパメモは、筑波AIハッカソン2026秋・チームBの共同制作です。メンバーは萱内一真と游方興。このページは、萱内一真の企画・技術検討・検証での貢献と、AIを使った範囲を整理しています。

## 人が考え、判断したこと

| 担当 | 具体例 |
| --- | --- |
| 目指す体験 | 部屋を3D化するだけでなく、収納に物を記録して「どこ？」と探す流れを設計 |
| 撮影と検証 | 実際の部屋を動画・写真で撮影し、スマートフォンで撮影、生成、移動、検索を確認 |
| 問題の発見 | 棚が壁と一体化する、壁の写真が貼れない、床と壁の向きが違う、ロッカーが薄いなどを発見 |
| 研究・手法の検討 | 論文や先行研究を調べる方針を提案し、点群、Gaussian Splatting、固定メッシュの用途・課題を比較 |
| 組み合わせの提案 | 位置合わせの改善と固定メッシュへの写真投影、対象の壁を指定した追加撮影を検討・選択 |
| UI・UX | 参考画面を提示し、撮影画面の簡略化、俯瞰と移動の切替、収納の強調表示、検索への導線を改善 |
| 優先順位と採否 | 実際の操作結果から、何を直すか、どの方法を試すか、どの見た目を採用するかを判断 |

## AIが支援したこと

- 先行研究・技術候補の調査結果を整理し、比較や組み合わせの案を提示。
- 要件に沿ったAPI・3D処理・UIの実装と既存コードの変更。
- ログ、ソース、画面から不具合の原因候補を調べ、修正を提案・実施。
- テストの作成・実行、動作結果の整理。
- 発表資料、技術補足、発表原稿、公開用ドキュメントの作成を支援。

実装にはAI生成・AI編集のコードが含まれます。AIの出力をそのまま完成とせず、人が実際に撮影・操作して結果を確認し、追加の指示と改善を繰り返しました。

## 改善の例：壁に写真が貼れない

1. **観察**：歩行表示で、撮影したはずの壁に大きな空白が残る。
2. **検討**：写真の枚数だけでなく、カメラの位置・向きと固定メッシュの対応を見直す。
3. **方針**：位置合わせを改善し、対象の壁を指定して撮った写真を利用する。追加撮影を順番に案内する。
4. **実装・検証**：AI支援で処理とUIを変更し、人が撮影と表示を確認して再調整する。
5. **残る課題**：遮蔽や無地の面は難しく、周囲の模様による補完と実際の撮影範囲を区別する必要がある。

これは改善の過程を説明するもので、全室での精度向上や定量的な優位性を実証したものではありません。

## 検討と実装を区別する

動画フレーム間隔の短縮や点群の平均化なども議論しましたが、検討した案をすべて実装・比較評価したとは記載しません。Gaussian Splattingなどの実験経路もありますが、主要な部屋表示は固定メッシュと写真投影です。

## 共同制作の帰属

この個人リポジトリは、チーム作品への貢献を紹介するためのものです。共同開発元、UIの出典、第三者技術の表示を残しています。コミット数や行数を個人の作業量・単独著作の証拠として扱っていません。
